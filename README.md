# TrustLens AI 🛡️
**See what the checkout hides.**

Built for **PromptWars × GEN AI CLUB, Presidency University**.

## 🚀 The Problem
Consumers and job seekers constantly lose money to deceptive web layouts, dark patterns, hidden fees, and forced continuity subscriptions. Most users cannot identify these UI tricks until they have already paid.

## 💡 The Solution
TrustLens AI is a single-page AI security scanner that analyzes e-commerce URLs and checkout screenshots to detect:
- Dark patterns & pre-selected options
- Hidden fee indicators
- Recurring subscription traps
- Phishing and urgency manipulation

## ⚙️ How It Works (Prompt -> Idea -> Create -> Innovate)
Using a carefully engineered prompt architecture, TrustLens AI acts as a cybersecurity assistant. It parses text or image context from the user and returns a structured JSON-like threat index, confidence score, and clear consumer protection advice. 

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **AI Engine**: Google Gemini API (gemini-3.6-flash)
- **Deployment**: Local / Browser-based

## 🔑 Setup Instructions
1. Clone this repository.
2. Open `index.html` in your code editor.
3. Replace the `GEMINI_API_KEY` placeholder with your active Google Gemini API Key.
4. Open the file in any modern web browser to run the scanner.

*Note: This is a hackathon prototype. For production, API keys should be moved to a secure backend environment.*
